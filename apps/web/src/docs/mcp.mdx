## Configuration & Setup

Nikala MCP supports both local Stdio execution and remote HTTP/SSE transports.

### Stdio Transport

Use Stdio with Cursor, Antigravity, Claude Desktop, and other local MCP clients. Add `@nikala-ui/mcp` to your MCP configuration file (`mcp.json` or the Claude Desktop configuration):

```json
{
  "mcpServers": {
    "nikala-ui": {
      "command": "npx",
      "args": ["-y", "@nikala-ui/mcp"],
      "cwd": "/absolute/path/to/your/project",
      "env": {
        "WORKSPACE_DIR": "/absolute/path/to/your/project"
      }
    }
  }
}
```

### Remote SSE Transport

For web-based AI tools or assistants supporting remote Server-Sent Events connections:

```text
Remote SSE endpoint: https://nikala.dev/api/mcp/sse
Messages endpoint:   https://nikala.dev/api/mcp/messages
```
