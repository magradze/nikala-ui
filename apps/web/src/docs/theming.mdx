## Supported Palettes & Accent Colors

Select from base gray palettes and dynamic brand accent colors.

<Callout type="warning" title="Amber Accent (#d97706)">
  The signature <code>amber</code> accent color provides a warm, energetic gold tone for your components.
</Callout>

### Base Gray Palettes

`zinc` (default), `slate`, `gray`, `neutral`, and `stone` are supported base palettes.

### Primary Brand Accent Colors

The available accent colors are `amber` (`#d97706`), `violet` (`#7c3aed`), `sky` (`#0284c7`), `emerald` (`#059669`), `rose` (`#e11d48`), and `zinc` (`#18181b` / `#fafafa` in dark mode).

## CLI Theme Commands

Switch brand accent colors or base palettes anytime without re-running initialization.

### Interactive Theme Selection Menu

```bash
bunx @nikala-ui/cli theme
```

### Direct Command Execution

```bash
# Set primary accent color and base gray palette
bunx @nikala-ui/cli theme set sky slate

# Set Amber accent
bunx @nikala-ui/cli theme set amber zinc
```

## Runtime Theme Manager

The `theme-manager` provides a zero-dependency theme provider, brand accent color customizer, border-radius controls, and transition animations.

Add it to your workspace:

```bash
bunx @nikala-ui/cli add theme-manager
```

<Callout type="info" title="Zero-FOUC Pre-Hydration Injection">
  Include <code>ThemeScript</code> at the root of your app before <code>ThemeProvider</code>. It runs synchronously before DOM paint and prevents white theme flashes during SSR.
</Callout>

Wrap your application root component:

```tsx
import { ThemeProvider, ThemeScript } from "@/providers/theme-provider";
import { ThemeToggle } from "@/components/ui/theme-toggle";

export default function App() {
  return (
    <>
      {/* Inject before DOM paint to eliminate SSR theme flickering */}
      <ThemeScript storageKey="nikala-theme" />

      <ThemeProvider defaultTheme="system" storageKey="nikala-theme">
        <div class="min-h-screen bg-background text-foreground">
          <header class="flex items-center justify-between border-b border-border p-4">
            <h1>Application Title</h1>
            <ThemeToggle mode="max" effect="circular" />
          </header>
        </div>
      </ThemeProvider>
    </>
  );
}
```

Customize `ThemeScript` fallback defaults:

```tsx
<ThemeScript
  storageKey="nikala-theme"
  defaultTheme="system"
  defaultAccent="amber"
  defaultRadius="0.5"
/>
```

## useTheme() Hook API

Access and mutate theme parameters programmatically inside any child component.

```tsx
import { useTheme } from "@/providers/theme-provider";

export function CustomControls() {
  const { theme, setTheme, accent, setAccent, radius, setRadius } = useTheme();

  return (
    <div class="flex gap-2">
      <button onClick={() => setTheme("dark")}>Dark Mode</button>
      <button onClick={() => setAccent("emerald")}>Emerald Accent</button>
      <button onClick={() => setRadius("0.75")}>Large Radius</button>
    </div>
  );
}
```

## CSS Tokens Reference

Standard CSS variables generated by `nikala init` in your main `index.css` or `app.css`.

```css
@import "tailwindcss";

@theme inline {
  --color-background: var(--background);
  --color-foreground: var(--foreground);
  --color-card: var(--card);
  --color-card-foreground: var(--card-foreground);
  --color-primary: var(--primary);
  --color-primary-foreground: var(--primary-foreground);
  --color-border: var(--border);
  --radius-lg: var(--radius);
}

:root {
  color-scheme: light;
}

.dark {
  color-scheme: dark;
}
```
