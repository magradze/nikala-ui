## Usage

Import the component into your SolidJS application:

```tsx
import { Avatar, AvatarImage, AvatarFallback } from "@/components/ui/avatar";
```

## Examples

### Fallback State

If the image fails to load or is unavailable, `AvatarFallback` automatically renders.

<ComponentViewer
