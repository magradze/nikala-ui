## What is Nikala UI?

<p>
  Tailwind CSS v4 introduced a CSS-first configuration (<code>@theme</code>), which broke compatibility with many existing SolidJS UI wrappers.
</p>

<p>
  Instead of adding a heavy third-party UI package to your <code>node_modules</code>, Nikala's CLI writes lightweight, fully reactive SolidJS components directly into your <code>src/components/ui</code> directory. You own 100% of the source code.
</p>

<p>
  Nikala UI is architected as a modern monorepo separating the command-line client (<code>@nikala-ui/cli</code>) from the core design system (<code>@nikala-ui/core</code>), allowing background registry updates without requiring CLI package updates.
</p>

## Quick Start

<p>1. Initialize Nikala UI in your SolidJS project:</p>

```bash
bunx @nikala-ui/cli init
```

<p>2. Add components directly to your workspace:</p>

```bash
bunx @nikala-ui/cli add button card input theme-manager
```
