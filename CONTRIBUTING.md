# Contributing to Nikala UI Web

Thank you for your interest in contributing to the official Nikala UI documentation portal and playground.

## Documentation Guides

Please review the following guides before opening a pull request:

- **[Component Documentation Guide](docs/COMPONENT_DOCS_GUIDE.md)**: Instructions for authoring component pages, live previews, and API reference tables.
- **[Playground Stage Guide](docs/PLAYGROUND_STAGE_GUIDE.md)**: Instructions for creating dynamic stage preview modules and TSX code generators.

## Local Development Workflow

1. Fork the repository and create your feature branch from `main`.
2. Install dependencies:

   ```bash
   bun install
   ```

3. Start the development server:

   ```bash
   bun dev
   ```

4. Verify production build locally:

   ```bash
   bun run build
   ```

5. Submit a pull request with clear conventional commit messages.
